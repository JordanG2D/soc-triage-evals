# External file transfer review

Check transfer direction, file type, source, destination path, parent process and authorized package or support activity. Unauthorized tool movement into an environment can be evidenced without later execution. Keep downloaded, written, executed and effective actions separate. Do not run a retrieved file to determine intent during triage.
