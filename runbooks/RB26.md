# Tool selection and stopping

State the unresolved question before using a tool. Choose enrichment or runbook retrieval only when it could resolve that question or establish a required policy. Once the retained alert and fetched evidence support the decision, stop. Do not repeat identical lookups, query unrelated identities or add tools merely to make the report longer. Keep the triage run within six tool calls.
