# Evidence and disposition

Separate observations, event interpretation and the triage decision. A completed suspicious action can be evidenced while the response still requires specialist review. Treat unavailable records as missing evidence. Do not replace gaps with a confident story. Record the smallest set of supported facts and the missing information that changes the decision.
