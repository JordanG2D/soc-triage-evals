# Repeated MFA prompts

Review prompt count, approval outcome, registered-device status and the account owner’s response. Many prompts can be a meaningful anomaly, but count alone does not prove coercion or bypass. An owner denial of the exact successful session materially changes the interpretation. Avoid claiming an MFA mechanism failed when only an accepted prompt is observed.
