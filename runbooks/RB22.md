# Package provenance checks

For a package explanation, match the manifest hash, valid signer, expected cache path, job identity and approved change window. An approved distribution address can serve many files; it does not establish trust in the selected file. A signature also needs a matching expected publisher and package. Stop at the supported provenance claim.
