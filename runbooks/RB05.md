# Script authorization checks

For a maintenance explanation, match the change to the script path, host, identity, destination and execution time. A general administration role is insufficient. Check what the script actually did. If the alert already contains the complete matching authorization and bounded routine actions, stop once the decision is supported instead of collecting unrelated enrichment.
