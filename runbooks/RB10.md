# Scheduled task registration

Collect the task action, principal, trigger, registering process and execution result. A recurring task running an unsigned file from a user-writable path under a privileged identity requires comparison with approved applications and changes. Task names are easy to imitate. Describe creation and actual execution separately; one does not automatically prove the other.
