# User context interpretation

Use account context when ownership, device assignment, role or authorization is decisive. Distinguish direct account-owner confirmation from a missing response. A service role or administrative title does not authorize every action. Preserve the exact session and time being confirmed, and explain when available user records do not resolve the alert.
