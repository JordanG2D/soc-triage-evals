# Triage handoff report

Return the disposition, severity, technique or null mapping, a short evidence-backed explanation and a concrete next action. Highlight material uncertainty and any review policy that changes the disposition. A report can identify an attack while requesting incident-lead decisions. Avoid prescribing destructive containment actions as if triage had already authorized them.
