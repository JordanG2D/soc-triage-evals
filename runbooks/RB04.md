# PowerShell process review

Review the parent, script path, signer, observed behavior, account and authorization window. A document application starting an unsigned script and a remote-control child deserves examination. PowerShell itself is a common administrative interpreter. A signed script is useful context but does not establish authorized scope. Report observed execution separately from later behaviors that were not retained.
