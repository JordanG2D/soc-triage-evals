# Host context interpretation

Use host context to check asset criticality, installed software, expected jobs, scoped changes and recovery. Match the observed path and timing rather than a broad product category. A complete bounded change ledger can establish no matching approval in that window; a missing ledger cannot. Criticality changes impact but does not by itself prove adversarial intent.
