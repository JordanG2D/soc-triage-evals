# Authentication fanout review

Check distinct accounts, time window, candidate-password cardinality, failures and successes. A small password candidate set across many accounts supports spraying; repeated failure alone does not establish that pattern. Never request or disclose actual passwords. Correlate a successful account with authorized testing and account-owner evidence before claiming compromise.
