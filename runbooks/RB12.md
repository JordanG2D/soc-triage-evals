# Outbound archive transfer review

An archive and high byte count can occur in backups and data theft. Determine the source process, contents where lawfully available, destination authorization and session history. The exfiltration-over-C2 mapping requires evidence that the data used an existing command-and-control channel. Do not map it solely from HTTPS, volume or an unusual destination.
