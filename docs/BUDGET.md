# Live spending contract

The project has a $20 lifetime cap across its live workflows, including any future judge calls. No judge calls are currently enabled. Provider keys are read from GitHub Actions secrets only during the paid step; no keys enter source, reports, or logs.

Each main-branch manual run first validates dependencies, the synthetic dataset, all tests, and the offline baseline. It then commits one $5 allocation to the repository journal using GitHub Contents API compare-and-swap against the current file SHA. A failed or ambiguous allocation write stops execution. The job proceeds only after durable acknowledgement, and verifies its lease against that exact public journal commit. Workflow concurrency serializes paid jobs; the journal's expected SHA also rejects competing writes. Repeated run attempts require distinct allocations. There are no automatic refunds or resets.

Within an allocated run, an atomic SQLite transaction reserves each request's full token bound. A byte-based input bound includes the complete serialized text and tool schemas plus 8,192 framing tokens. Input is limited to 100,000 tokens, output to 1,024 tokens, and the agent to five generations and six tool calls. All input categories, including caches, are charged against the internal allocation at $4 per million tokens and output at $10 per million. Those conservative ceilings exceed the two allowlisted models' declared standard rates. Missing usage and ambiguous request failures hold the full reservation. An exceeded token bound persistently halts the ledger. SDK and Inspect retries are disabled.

The actual model cost field is a standard token-price estimate from reported uncached input, cache reads, cache writes, and output. Anthropic cache writes use the conservative one-hour price if duration is unavailable. The internal ceiling is reported separately; neither is presented as a retrieved invoice. No hosted tools, paid retrieval, provider fallbacks, fast service tier, or regional processing are requested.

Declared prices checked on 2026-11-12: [OpenAI GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) standard input $0.10/M, cache read $0.01/M, cache write $0.125/M, output $0.50/M; [Anthropic pricing](https://platform.claude.com/docs/en/about-claude/pricing) Haiku 4.5 input $1/M, cache read $0.10/M, one-hour cache write $2/M, output $5/M. Review these prices before enabling another paid run if provider terms change.

The cap bounds authorized execution of this repository's fixed workflow. A repository owner can change code, change the journal, or use a key elsewhere; those actions fall outside this program's controls. GitHub runner loss, timeout, or provider uncertainty can consume an allocation without producing a complete report. The project preserves that conservative allocation rather than assuming a refund.
